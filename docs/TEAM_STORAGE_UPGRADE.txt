多人空间与存储升级 / 20261019-team1

1. 远程入口按已授权 Tailscale 用户路由至独立进程、SQLite 数据库和文件目录。
   管理员历史保留在 data/，其他账号数据位于 data/workspaces/<哈希账号标识>/。
   不自动猜测旧历史归属，不复制旧素材、任务、聊天或草稿到其他账号。
   密钥与模型运行组件由主机统一管理；远程成员不能修改这些管理配置。
2. 文件与空间：用户查看自己的文件、回收站、任务和提交记录；管理员可检查已授权用户空间。
   单空间默认20GB，主机预留5GB，单用户上传同时1个，新生成请求最多每空间2个、主机4个。
   上限是保守准入约束，重任务可能同时持有多个工作记录，实际可接纳数可能更低。
3. 取消引用不会释放空间；移入回收站保留7天，永久删除会失去相关历史文件的播放/下载能力。
   不把浏览器下载视为成功备份。不自动删除上传素材或成片。清理跳过运行中及不确定任务。
   自动清理每30分钟检查一次，仅处理到期回收站、已知可重建缓存和过期临时片段。
4. 浏览器为每次操作保存独立提交编号，未确认完整响应前重用原编号；无编号的调用按相同参数保守去重10分钟。处理中或结果未知的相同请求禁止重发。
   进程中断保留未知记录。人工核对仅保存核对结果，不会触发自动重新生成。
   此机制不能撤销供应商费用，也不能证明供应商账单已结算。
5. 大文件采用分段输出；应用日志轮转。管理与本机专属按钮在远程界面减少误操作。
   官方 Hypit 可视化编辑器仍仅限主机打开，暂不向远程浏览器代理其独立服务。
6. STUDIO_WORKSPACE_QUOTA_GB / STUDIO_DISK_RESERVE_GB / STUDIO_USER_CONCURRENCY /
   STUDIO_GLOBAL_CONCURRENCY 是主机管理环境参数，变更后重启相应后台生效。
7. 更新：先暂停入口、检查全部用户的运行/未知状态、SQLite在线备份、源码哈希复核、
   离线回归、切换与健康检查，失败保留备份并回退。现有单实例 deploy.py 在多空间模式下拒绝直接切换。

验证：21项新增单元测试、23项入口回归、8项身份路由测试、真实双后台HTTP模拟测试。
