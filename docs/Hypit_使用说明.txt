Seedance Studio：AI 视频制作（官方 Hypit）使用说明

一、先准备
1. 新目录解压完整安装包，运行 01_INSTALL.cmd；看到安装通过后运行 00_START.cmd。
2. 在“状态与设置”保存 OpenLux API 密钥、账号只读令牌；需要上传参考素材时配置 OSS。
3. 聊天和工程保存在本机；使用 OpenLux 时模型推理在云端。本软件不是离线大模型权重部署。

二、制作一个视频
1. 在 Hypit 菜单上传并勾选参考视频。按需附加自己的商品图片、视频或音频。
2. 写明目标：商品、受众、时长、画幅、镜头、字幕和声音要求。例如：
   “把我的杯子实物视频做成8秒的9:16广告。先展示杯口，再展示握持特写，结尾写‘陶瓷杯’。只用已有素材，不生成新镜头。”
3. 保存制作任务。保存不扣费。
4. 读取 AI 编排报价，填写预算和最多尝试次数，勾选授权后点击“开始 AI 编排”。
   AI 会读取素材分析、编写官方工程、接收 check/plan 错误并尝试修正。
5. 只使用已有素材且官方检查通过时，自动进行免费的本地合成，完成后预览或下载。
6. 需要新镜头时，任务停在等待视频授权。先查询视频报价；参考素材需要另行确认上传及不含真实人脸。
   只有再次确认报价和单次视频预算后，才会提交视频生成。编排预算不等于视频预算。
7. 高级操作中可以检查工程或打开官方 Studio 编辑器。修改工程或素材后需要重新校验和报价。

三、从商品和 TikTok 脚本进入
1. 商品知识中心：上传商品证据，整理关键词，人工确认真实商品事实。
2. 热点收集：按商品关键词预览 Bright Data 查询；明确确认额度后提交一次采集。
3. 选择候选，取得真实视频或手动上传绑定。播放量只能说明传播指标，不等于销量或转化率。
4. 预览 GPT 报价，确认后拆解真实时间戳画面，匹配当前商品并生成双语脚本。
   不匹配、缺少事实绑定或市场规则不通过的脚本进入待复核，不进入可用脚本队列。
5. 智能视频制作：确认脚本，选择当前商品的实物素材，点击“建立并打开 Hypit 制作任务”。
   商品事实、限制、脚本和真实视频拆解一起绑定工程。重复点击复用同一工程。
6. 按第二部分确认编排预算，后续自动编排/本地合成；生成新镜头仍有独立报价确认。
目前采集、脚本、编排和视频生成有分段费用授权，不是无人值守、无限扣费的批量系统。

四、出错时
- 浏览器刷新不会重新提交模型或视频生成。先刷新本地任务和记录。
- 远端已确认任务时，使用“仅恢复原任务”，不要重新创建同样的视频任务。
- 结果未知时停止自动重发；核对供应商任务或账单，保留任务编号和本地诊断。
- GPT 对话提供“刷新本地记录”和“保留旧请求，继续新问题”。后者不会重发旧问题，也不表示旧费用为零。
- FFmpeg/ffprobe 安装失败会阻止完整安装通过；查看 install_logs/dependency_report.json 后可安全重跑安装。
- Cloudflare 调试隧道默认不安装，OSS 不依赖它。程序不会为了下载而关闭 HTTPS 证书验证。

五、能力范围
已实测的旧版集成基线：官方 Agent 编写/检查/规划、本地 Film/Studio、文生视频、单个非人物参考视频编辑、原任务 GET-only 恢复。
延长、其他参考组合仍为实验功能。真人脸直接参考与音色克隆未支持。
本轮新版安装、启动、本地合成/编辑器和附件存储已通过；粘贴截图、拖放和新版布局仍待浏览器交互验收。
历史记录用于查询本地调用和任务；实际费用以 OpenLux 账单为准。生成前的报价仍为预估，供应商无费用硬封顶承诺。
