# 源码与共同根因

日期：2026-10-20。项目为 Seedance Studio，当前仓库是唯一源码根。基线 Git 为 `1a4c65d9edee9b906092c0b2e5bd107c17d386c9`，已保留源码 ZIP 检查点。本轮未提交、推送或部署。

实际修改覆盖配置服务/凭据、模型传输、桌面宿主、安装/打包、数据迁移、输出索引、SQLite 快照、Hypit Runtime、更新器、前端维护页及回归工具。未修改其他商品孵化项目或在运行的网站。

共同根因及治理：

- 安装资源、用户数据和旧安装绝对路径混用：统一 resource/user home，持久记录输出根，旧工程受控重绑定并留备份。
- 界面设置与真实调用不同步：统一服务商快照和模型解析，配置 revision 冲突校验，真实请求传播所选超时和模型，聊天默认值随保存更新。
- 桌面 localhost 继承系统代理：健康检查绕过代理，并核对 PID、端口、版本、资源根和数据目录。
- 初始化失败清理范围不完整：从成功绑定端口起纳入 finally，仅移除本进程 PID。
- 依赖可导入但运行不兼容：真实转写发现 PyAV 19 移除参数，独立验证后选用 18.1.0，固定完整传递依赖。
- 更新预检与写入有竞态：付费提交和普通写入均在同一控制库事务内登记；维护 gate 持久化，未知付费状态不自动重提。
- 旧安装布局与 updater 不一致：明确安装根/版本根，新版本进入独立目录，回滚保护旧程序、快照和快捷方式。

源码测试成功不能证明所有外部服务均成功，也不能承诺零 BUG。最终构建文件和测试日志需要以同一次源/依赖指纹关联。
