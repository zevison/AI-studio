# 性能证据边界

`tools/measure_desktop_performance.py` 为真实 EXE 的两个独立 GUI 启动记录就绪时间、存活子进程 CPU、private bytes 合计峰值、线程及退出码。第一轮新用户数据，第二轮保留同一隔离用户数据；不调用付费接口。

统计只覆盖观测到的存活进程，不把 working set 共享页重复当作独占内存，不宣称两次启动构成统计学基准。最终采样结果必须随具体构建 SHA 交付，本文件不填尚未执行的性能数字。

本地 ASR 限一份模型并发加载，避免多个分析任务重复占用模型内存；旧 CPU 先检测 AVX2。UI 更新检查和下载异步执行，进度与真实字节关联，不自动安装。

125/150/200% 原生 Windows DPI、长期内存泄漏和不同硬件吞吐仍未验证。
