# 配置与凭据

已实现类型化配置、schema/revision、原子发布、并发冲突、账号隔离、服务商参数快照和导入导出。新账号不复制旧账号 credential_ref。密钥不进入浏览器缓存或导出。

Windows 凭据使用 DPAPI。损坏/跨用户不可读时保留原字节，界面允许显式重新授权并留备份，禁止以空配置静默覆盖。官方 Hypit、余额和报价单独解析官方账号，不能把自定义代理的密钥发送给 OpenLux。

输出目录、FFmpeg/FFprobe/Chromium 程序路径可配置，明确哪些需要重启。历史输出根有非敏感索引，切换目录后原成片仍可核实。聊天记录及附件在本机持久保存，推理通过配置的服务执行。

自定义协议限实际支持的公网 HTTPS 路由和类型化参数，拒绝重定向、私网/元数据地址及跨账号转发；不宣称支持任何任意 API 或本地模型协议。
