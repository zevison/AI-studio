# 数据库、迁移及恢复

当前 schema 为 390。已有数据库升级前使用 SQLite backup API 保留含 WAL 的一致快照，未来 schema 拒绝启动。首次目录初始化和旧数据迁移均保留来源、不覆盖现有目标。

任务和付费收据持久化。启动恢复将不确定提交保留为未知，不以超时推断免费或失败。配置和路径变更不自动触发付费重发。

build3 的真实 EXE 已执行：重启后配置/工程/成片 SHA 保持；改变输出目录后原链接仍返回原字节；未来 schema 拒绝；恢复独立 WAL 快照后旧程序重新启动，业务行和两份成片哈希相同。此项是当前 OS 隔离副本测试，不是全新 OS 系统重启。

新增更新器在同一控制库事务中阻止任务及普通写入，并快照所有业务库。回滚前比较业务内容指纹；新业务库、新业务写入、变更的配置或凭据均阻止自动覆盖。仅 schema 标记、启动时间和空迁移表不算业务写入。恢复中断保留 gate、失败版本及快照，不能宣称已经自动修复。

跨机器 Windows DPAPI 不能通过复制自动解密，需要新机器重新授权。真实系统重启、跨版本原生安装器回滚仍待最终环境证据。
