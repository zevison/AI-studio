# 安全边界

设置/更新等敏感写操作要求本机 Host/Origin 和会话令牌。普通写入与付费调用均尊重持久维护 gate。令牌只在页面内存中使用，不写 localStorage，不转发给外域。

下载验证 HTTPS 来源、重定向边界、大小、有限时间和 SHA；更新额外使用 TUF 和 Authenticode 证书 SHA256 allowlist。无生产信任配置时 BLOCKED，不存在前端提交任意 root、URL 或安装路径的接口。

源码和冻结 payload 使用敏感内容扫描；唯一公共 CA PEM 通过确切版本/RECORD 及文件内容核对，不放宽其他 PEM。诊断 ZIP 只含版本和状态白名单，不含原始日志、数据库、密钥、对话、媒体或本地路径。

已测风险包括：损坏凭据保留、依赖 SHA 篡改、非受信来源、付费结果未知不重发、并发重复提交、迁移路径逃逸和未来数据库拒绝。静态扫描不是不存在秘密或漏洞的数学证明。

正式 Authenticode 证书、线上签名更新仓库及 Defender/SmartScreen 多机声誉验收未完成。不得降低校验、关闭防护或安装假证书来消除这些门槛。
