# 后台组件与更新规则

R3.14 保留联网组件构建选项 `--download-components`。默认完整离线构建仍保留。
联网版仅把本地语音模型、视频合成浏览器移到后台下载；WebView2、Python、
Node、FFmpeg、OCR、Hypit SDK 仍在安装包内。首次打开后可在
“状态与设置 → 应用维护 → 插件与组件”确认安装，再查看进度、暂停、继续和重试。
首次启动不自动下载全部组件；按需自动下载和中断自动恢复默认关闭，授权绑定具体版本。
暂停或断线保留断点，不会在每次启动时反复安装 Python/npm。

## 国内来源

- Node、Chrome for Testing：cnpm 维护的 npmmirror。
  维护方映射：https://github.com/cnpm/binary-mirror-config
- small 语音模型：ModelScope 的 Systran/faster-whisper-small 镜像。
  https://modelscope.cn/models/Systran/faster-whisper-small
- 每个来源均必须与构建锁的 SHA-256 完全一致。镜像标签即使变化，程序也不能
  接受不同内容。不使用 GitHub 下载代理或关闭 HTTPS 校验。
- OCR 暂无已验证的匹配国内源，继续内置。官方源保留为有限次数回退。

本机连通性不代表所有同事网络均可访问。国内源异常时显示失败原因，可继续下载；
始终保留已有完整离线版作为不依赖在线组件源的交付选项。

## 更新与回退

1. 当前软件只接受安装时内嵌清单锁定的版本和文件大小、哈希。
2. 下载源只负责传输，不能通过远端“latest”清单改变版本或安装脚本。
3. 升级候选在独立环境验证兼容性、安全公告、许可及关键功能，再通过独立 TUF 插件仓库发布。
   未配置正式插件信任根时维持关闭，仍可随完整软件更新内嵌清单。
   不让 Dependabot 或镜像站直接替换客户正在运行的组件。
4. 文件下载、校验和安装使用临时目录，完整校验后原子激活。损坏文件隔离保留，
   旧版本使用不同身份目录，安装新版不会覆盖它，回到旧程序时仍可使用旧组件。
5. 组件不涉及数据库迁移、密钥或任务目录。组件未就绪时相应能力不能显示成功，
   Hypit 新付费制作会在花费前拒绝；已有任务查询与结果恢复继续保留。
6. 自动软件升级仍遵守原有 TUF/发布签名门槛，未配置正式信任根时维持 BLOCKED。
   本功能没有放开远程 EXE 更新权限。

构建：在锁定的 Windows 构建环境给 `tools/build_desktop_exe.py` 增加
`--download-components`。运行时清单由 `build_component_catalog.py` 从完整、
已校验的模型锁与浏览器解压内容生成，不从开发机用户数据推断。

验收必须分别记录：离线异常测试、国内源完整文件校验、实际组件安装与执行、
打包后首次启动，以及全新 Windows 电脑验收。不得互相冒充。

完整生命周期、原生检测隔离、离线导入、崩溃恢复及独立插件签名更新的启用条件
边界，见 `PLUGIN_LIFECYCLE.md`。此候选版不能标记正式稳定版。
