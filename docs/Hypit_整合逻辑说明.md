# Seedance Studio V2.4.2｜Hypit 逻辑整合说明

## 这次真正加入了什么

本版本把 Hypit 的核心方法部署成本地工作流契约：**完整工作流、分轨、可编辑、可重跑、词锚点优先、结构与替换内容分离**。没有复制或打包 Hypit 官方源码，也没有强制引入 Node / Chromium / Coding Agent 全套运行时。

换句话说：采用 **Hypit 方法论 + Seedance Studio 轻量本地分析引擎 + Seedance 2.5 最终动态生成**。

## 本地解析链路

1. 读取真实视频元数据：时长、尺寸、帧率、音轨存在性。
2. FFmpeg 基于画面内容变化检测真实镜头边界，不按固定百分比硬切。
3. 每个镜头段抽取中间关键帧。
4. 分析静音/低音量区间，形成音频结构轨。
5. 若已安装 WhisperX，优先生成逐词时间轴；否则若安装 Faster-Whisper，则用本地轻量方案生成逐词时间轴。
6. 若已安装 Tesseract，对关键帧做画面文字识别。
7. 建立多轨工作流：footage、dialogue、captions、broll_candidates、effects_candidates、audio。
8. Hook / 证明 / CTA 等结构角色只能作为带置信度与证据的候选，不允许把推测写成确定事实。
9. 有逐词时间轴时用 word anchor（词锚点）；没有时回退 time anchor（精确时间锚点）。
10. 用户保存 V2 / V3 等分支并明确确认后，才进入公网素材自检与 Seedance 付费阶段。

## 与 V2.4.0 的根本区别

V2.4.0 曾按固定 4% / 24% / 50% / 74% / 94% 抽 5 帧，并按固定百分比给视频段落套“钩子/主体/演示/结果/CTA”名称。V2.4.2 已彻底移除这套旧函数。

现在的镜头边界来自真实内容变化；语义标签显示置信度与证据；口播存在本地逐词引擎时会进入独立 dialogue 轨。

## 为什么没有把完整 Hypit 官方程序强塞进主安装包

Seedance Studio 的目标仍是普通 Windows 电脑尽量一键部署。完整 Hypit 官方生产环境面向编程智能体，可能牵涉 Node、pnpm、Chromium、语音对齐与其它运行依赖。强制合并会显著增加安装失败率、体积和维护成本。

所以主程序只吸收方法与工作流结构；如果未来确实需要 Hypit 官方渲染器，再做独立桥接层，而不是污染本地工作台主链路。

## 付费测试 Gate（闸门）

默认基础 Gate 至少要求：
- 视频元数据正常；
- FFmpeg 内容驱动镜头检测成功；
- 至少抽出 2 个有效关键帧；
- 证据完整度达到最低门槛。

设置中还有“逐词锚点严格门槛”。默认关闭，因为纯音乐/纯动作视频不应被无意义阻塞；对于口播型爆款，建议首次付费测试前开启。开启后，只有真正获得逐词时间轴才允许确认工作流。

## 公网参考素材 Gate

付费 Seedance 调用前自动按设置策略检查公网素材：
- 默认先 Quick Tunnel；
- 必须通过 HTTPS / HEAD / Range 检查；
- 失败后自动尝试已配置的固定 HTTPS 备用通道；
- 全部失败则直接停止，绝不先提交付费任务再碰运气。

所有本地公网素材 URL 使用 HMAC 签名 + 过期时间，并且素材服务只允许读取。
