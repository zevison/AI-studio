Seedance Studio R3.6：新电脑安装可靠性修复

交付状态：完整安装候选包。包含安装、启动及新电脑验收入口；不是免安装便携程序，也不是已完成所有电脑兼容性认证的最终版。
普通安装：完整解压到可写的本地短目录，运行 Studio\01_INSTALL.cmd，成功后运行 Studio\00_START.cmd。
首次安装仍需要联网取得 Python 和 Python 依赖；Hypit SDK、浏览器及已打包的视频组件随完整包提供。保留 HTTPS 证书和文件校验，不通过关闭安全验证解决下载错误。
候选系统范围：Windows 10 build 19041 及以上、Windows 11，x64；ARM64、32位系统未验收。

本次修复：
1. 每个版本使用自己的 .venv，不再链接到旧版本或公共 Python 环境；避免删除旧目录后新版本失效，以及一个版本安装时改动其他版本正在使用的依赖。下载缓存仍可复用，磁盘占用会增加。
2. 发现旧的链接、损坏或不兼容环境时先改名保留，创建失败不删除旧环境；备份名增加随机后缀，防止短时间重复安装冲突。
3. 整轮安装加用户级文件锁，防止同一账号同时安装不同目录、竞争写入公共 SDK 缓存；在运行库解包和 .venv 修改前检查工作台是否仍在运行。
4. Python 下载正文停传30秒或正文总时间超过8分钟时失败退出；断流不能被记为成功，可重试安装。签名及完整性检查继续保留。
5. 启动前确认 Python 3.12 x64；Windows Script Host 缺失或启动返回失败时，尝试 PowerShell 隐藏启动，仍由原来的启动锁和健康检查避免重复后台。
6. 安装目录不可写时直接提示换到可写目录；CMD入口禁用延迟变量展开，避免含感叹号路径被错误展开。

本轮证据：Python回归370项通过、1项跳过；前端32项通过。真实本机验证包括21MB下载、断流失败、30秒停传超时、跨进程安装锁排他与释放、中文及空格/&/%路径下独立Python，以及备用隐藏启动。
红队检查一：第二安装进程被拒绝，释放锁后重新获得锁；未测试绕过安装入口手动改缓存。
红队检查二：环境创建失败时旧环境文件仍保留；运行中的工作台阻止环境修改。
红队检查三：断流、停传均未返回下载成功，不关闭证书验证、不触发任何付费模型。
