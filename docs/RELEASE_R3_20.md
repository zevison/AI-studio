# Seedance Studio 5.2.0 (R3.20)

本版为 **付费安全与任务恢复** 版本，在 R3.19 自动更新修复的基础上，补齐本地付费预算/熔断、H3 清晰度导出、任务状态一致性，并刷新前端缓存键。

## 主要改动

- **新增本地付费预算上限与异常消费熔断**
  - 设置项：预算上限（美元 / 统计窗口）、统计窗口（小时）、窗口内付费提交熔断次数。
  - 付费提交在「消费确认令牌」之前拦截；被拦截时不调用任何付费接口。
  - 金额口径为本机 `usage_events`（实际扣费优先，缺失时用估算补齐），界面明确标注「不代表 OpenLux 最终账单」；没有金额记录的任务计为「费用待核实」。
- **H3 1080P 导出修复**
  - 菜单与接口大小写差异（1080P / 1080p）不再被判为不支持。
  - 1080P 仍为「按 2K 生成 + 本地 FFmpeg 缩小」，按 2K 档位预检费用。
  - 模型实际返回短边低于导出档位时，保留原生分辨率并写入真实提示，不再在已扣费后报错。
- **任务状态一致性**
  - 读取嵌套 `task` / `data.task` / `result.status`，任务自身状态优先于包装层。
  - 重启后对「已提交但无平台任务号」的视频任务标记为 `submission_unknown`，释放并发额度，不自动重提。
  - 新增「绑定平台任务号」：人工填入平台任务号后仅做只读查询，恢复进度或标记失败，不重复付费。
- **版本与缓存**：`APP_BUILD` 提升至 R3.20，`app.js` 缓存键同步刷新。

## 升级说明

- 支持从 V5.0.0 / R3.17 / R3.18 / R3.19 直接升级到本版（累积升级）。
- 覆盖安装即可：不会删除 API 密钥、商品资料、视频项目、素材与历史记录。
- 用户数据仍位于 `%LOCALAPPDATA%\SeedanceStudio`；本版未改动数据目录结构。
- 若升级失败，可重新运行旧的 R3.19 安装包回滚，用户数据不受影响。
