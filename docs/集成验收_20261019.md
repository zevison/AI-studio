# Seedance Studio 5.2.0 集成验收

本报告区分真实接口、官方本地运行和模拟测试。完整安装包指完整源码、依赖载荷及安装启动入口齐全，不表示供应商所有模型和业务能力都已验收。

## 已实测的集成链路

- 固定官方 Hypit 0.3.1，实际 TypeScript SDK 编译、Provider 注册及 Runtime 激活，40 项 SDK 测试通过。
- 官方 Skill 驱动受控 Agent，能够读素材分析、编写 SVML/SVS/SVRun、接收官方编译错误并修订。工具不开放 shell、密钥、付费构建或任意项目包执行。
- 两种不同时长本地参考工程、Film 合成、官方 Studio 和成片导出通过；不是固定 15 秒模板。
- 实际 OpenLux Seedance 2.5 文生视频：4 秒级、720×1280、24fps，费用 US$0.611134。
- 实际单个非人物参考视频编辑：红色杯子白色背景改为蓝色，4.041667 秒、720×1280、24fps，最终无声；净费用 US$1.000512。
- 参考编辑首次工程需要主机语法/类型适配及帧边界修正，全部原始源码和修复哈希保留，不能称为未经修改的 Agent 成果。后续独立 Agent 验收无需主机改写源码，通过官方 check/plan 和静态素材、提示词、参数绑定检查；未为该独立工程另行生成视频。
- 同一远端参考编辑任务因本地回执长路径、全长裁剪小数误差而中断后，GET-only 恢复、收集、合成成功。恢复层明确禁用生成 POST，未再次生成。
- 最终音频策略在官方 HTML 渲染后再次执行，去掉自动添加的无声 AAC 音轨，保留视频流及帧数。

全部测试实际费用 US$1.626442，其中早期首批 LLM 为 US$0.001338；原追加 US$5 授权范围内共用 US$1.625104。

参考编辑账单预扣 559872 quota，退款调整 -59616，净额 500256；按账号当前 500000 quota/USD 为 US$1.000512。预扣和退款用共同 request_id 关联，且净额与 actual_quota 一致。账单未直接提供该 task_id，任务关联依据隔离模型/时间窗口及同一供应商请求记录，不能声称账单有直接 task_id 精确匹配。

## 红队审查

1. **重复扣费、未知状态和跨站调用**：真实 loopback HTTP 的伪造凭据、外站 Origin 被拒绝；并发提交只能占用一次持久化授权；远端接受后本地崩溃、应答丢失、重新打开数据库均禁止自动重发。参考编辑实际恢复仅查询原任务。
   供应商确认任务时即原子记录任务身份和一笔费用预估，后续本地合成失败不会隐藏费用；恢复不会重复计入生成费，实际金额未对账时保留未知。
2. **文件逃逸、供应链载荷和缓存篡改**：拒绝 ZIP 路径穿越、保留设备名、大小写重复、符号链接及哈希不一致；隔离共享运行目录按内容哈希复用。已收集视频的回执绑定完整请求哈希、任务 ID 与文件 SHA256，错误任务或文件被篡改时拒绝返回。
3. **用户数据升级丢失**：不直接复制运行中的 SQLite 主文件，不合并覆盖目标用户数据库；使用 SQLite backup 包含 WAL 中已提交历史；复制失败保留原目录与暂存证据。回退不倒退覆盖新版数据。
4. **凭据泄漏与素材混淆**：Node 子进程不继承密钥类环境变量；随机 loopback 能力仅绑定当前请求；上传校验实际字节、唯一 OSS 对象、ETag、版本（有版本时），人物分类不明不放行；日志不记录签名链接或授权值。

## 明确未验收/不支持项

- 当前人物素材库路线、直接真实人脸引用、音色克隆不支持，不能称为已经实现。
- 其他参考生成、延长、图片/音频混合条件为实验功能，不能把一个单视频编辑测试外推为全部模态验收。
- 本机安装测试复用了已有 Python/Tesseract，未声称测试了干净 Windows 镜像、所有显卡和音视频素材。WhisperX 原生 TorchCodec 解码分支仍有依赖警告；本地预载波形路径和所有语言识别质量未逐一验收。
- 视频内容理解和商品外观一致性不存在普遍质量保证；已实测的杯子案例不等于真实电商广告批量复制质量通过。
- 供应商不提供费用硬封顶；门禁基于真实账号费率、受控规格和预算预留，最终以账单为准。
