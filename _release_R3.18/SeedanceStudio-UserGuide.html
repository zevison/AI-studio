01 · 首次安装与升级

  1. 运行 Seedance Studio 的 EXE 安装程序，按简体中文向导完成安装。核心运行环境随安装程序提供，不需要自行安装 Python、Node 或执行 pip 命令。
  2. 通过桌面快捷方式启动。首次启动可能比后续慢；等待窗口中的服务与页面就绪。不要连续双击创建多个实例。
  3. 进入“状态与设置”配置模型账号。未配置密钥时可查看本地界面、说明和已有记录，无法调用云端模型。
  4. 语音识别模型与视频合成浏览器按功能需要安装。请联网并保留足够磁盘空间；核心安装成功不表示所有可选组件已经安装。
  5. 升级前先创建迁移备份，再安装新 EXE。不要手动删除用户数据目录，不要把旧版数据文件直接覆盖新版数据库。回退前需核对数据库兼容性。

当前版本为验收候选版。开发机安装成功不等于所有 Windows 10/11 电脑均已验证；公司权限策略、系统版本、CPU 和网络都可能影响使用。遇到启动错误，请保留诊断记录。

02 · 账号、模型与余额

  1. 打开“状态与设置 → 模型与服务账号”，填写账号名称、协议、Base URL、API Key 和实际模型 ID。使用供应商给出的准确值。
  2. 聊天、图片、视频可以分别选择账号。OpenLux 原有账号同时用于官方报价、余额及适用的 Hypit 云端能力。自定义 OpenAI 兼容聊天接口不代表也兼容图片或视频。
  3. 保存配置，再核对页面顶部“实际请求模型”和各功能当前选中的模型。更改全局默认不等于覆盖所有页面的单次选择。
  4. 右上角余额可刷新并查看说明。优先使用 OpenLux API Key 查询；无账户权限时才需要在设置中绑定备用账户访问令牌。余额不是免费调用额度。

密钥保存在当前 Windows 用户的本机加密凭据中。留空通常表示保留原值，清除必须使用对应按钮。换电脑或换 Windows 用户后应重新配置；不要把密钥贴进聊天、截图或发送给其他人。

“暂不可用”表示未能读取，不能解释为余额为零。报价不完整时不能据此承诺生成成本；以对应账户实际账单为准。

03 · 菜单与完整工作流

“商品 → 热点 → 脚本 → 审核 → 视频”保留人工确认与费用 Gate，不是无人值守、无限重试的全自动赚钱流程。GPT 对话内容不会自动成为商品事实或制作任务。

04 · 商品知识中心

  1. 创建或选择商品，填写名称、目标市场、真实卖点、适用人群、使用方法及限制。
  2. 补充可核实的规格、配件清单和产品参考图片。没有证据的尺寸、认证、销量或性能应留待核实，不能让模型补造。
  3. 保存后核对商品是否正确；涉及模型分析时，先看所选账号及费用提示。
  4. 进入热点收集，明确选择这个商品。修改商品后，重新检查已有脚本是否仍适用，不要认为旧脚本会自动全部更新。

建议一款产品保留清晰稳定的身份。不要用其他型号图片或不同配件版本混作同一款。

05 · 热点收集

  1. 先在设置中配置 Bright Data，并人工核实账户当月免费记录与超额收费规则。本地停止线不是供应商赠送额度。
  2. 选择商品、目标市场和采集条件，手动触发采集。没有明确额度或预算时停止，不要反复点击。
  3. 查看采集记录、来源链接及可用证据。记录热度不等于证明销量；失败、缺失或未验证数据不能当作真实结论。
  4. 选择匹配的参考视频，执行素材分析与拆解。完整本地分析通常需要取得可读取的视频文件；只有链接并不保证能下载。版权、平台限制及来源网络可能阻止下载。
  5. 基于拆解结构和商品事实生成脚本，核对镜头、使用动作、文案和产品身份，然后交给智能视频制作审核。

Bright Data 属于第三方服务，可能收费；手动触发并不等于免费。没有采集证据时不要把 AI 推测标为“TK 爆款事实”。

06 · 智能视频制作

  1. 选择已保存商品与热点脚本；没有可用脚本时先回热点收集完成上一步。
  2. 检查并编辑脚本，选择测试视频模型，创建制作审核任务。模型名称出现在列表不代表当前账户已开放该能力。
  3. 核对商品、来源、素材、时长和预算，再发送到视频创作；确认预览后才提交付费生成。
  4. 成片下载完成后，在“效果与成本验收”选择对应任务，先运行免费的本地技术检查。
  5. 对商品事实、连续性、动作自然度、指令符合度、成片可用度分别评分。商品事实核对属人工责任；实际可用需每项至少 3 分、平均至少 4 分且技术检查完成。不能为了通过而虚填评分。

没有完成的本地成片时，评分与确认项不可使用。生成成功只说明模型返回结果，不能替代广告可用性、真实性和授权审查。

07 · 视频创作与素材引用

  1. 选择模型与视频模式，填写提示词。智能参考模式会结合素材类型判断适用模式；生成前仍需核对实际预览。
  2. 上传真实图片、视频或音频。输入 @ 从素材选择器插入引用，不要只输入没有绑定文件的标签。
  3. 选择比例、时长与清晰度，点击“预览本次调用”，核对实际模型、接口模式、参考素材与报价。
  4. 确认参数与费用后，再点生成。提交成功只是开始，必须等待任务完成、下载并校验输出文件。

音频的两种含义

添加音频后才显示对应使用方式。“音色参考”用于表达声音特征参考，不能承诺供应商支持真实声音克隆；“使用上传音频的内容”会按实际适配流程复用原音频内容。两者不等同。先裁剪、试听并确保授权，口播内容和成片时长需相互匹配。

参考素材上传到 OSS 仅在相关云端流程需要时进行。配置私有 Bucket、公网 Endpoint 和临时签名链接；不要使用 internal 内网 Endpoint。云存储与流量可能另行收费。

08 · AI 视频制作 · Hypit

  1. 打开菜单，按提示安装视频合成浏览器。刷新素材与工程，上传或选择需要的真实素材。
  2. 用自然语言说明想做什么，例如：“用这三张产品图做 8 秒竖屏介绍，字幕仅使用已确认的卖点，结尾展示产品名称。”
  3. 建立工程，核对模型账号和 Agent Token 报价，填写本次预算与最多回合，再明确授权编排。LLM 编排可能收费，本地合成本身不代表调用视频生成模型。
  4. 查看生成工程的校验结果与运行记录，检查素材绑定、字幕、时序和输出规格。校验失败应先修复，不要把失败工程当成已导出视频。
  5. 通过预览、官方 Runtime／CLI 的实际构建与导出后，在输出目录查看成片。需要新镜头时，仍须单独核对模型支持与视频费用并授权。

本地浏览器合成、LLM 工程编写与云端视频生成是三个不同环节。官方集成不意味着所有线上模型或参考编辑功能均对你的账号可用。人物参考、音色克隆或未适配能力不能凭提示词保证实现。

09 · 图片生成与视觉指令

文生图填写完整画面要求；图生图先选择起始图，再说明要修改的部分。“深度生成”基于当前结果继续修改。每次云端生成可能收费。

展开“图片视觉指令”，可以搜索、分类、收藏、选择并查看完整提示词；确认后应用到图片生成。/accessories 等是本地模板快捷码，不是模型隐藏功能。模板涉及内部结构或尺寸时必须补充证据。

结果可加入视频参考素材或设为下一轮图生图起点。历史版本用于查看与继续修改，不会凭点击旧版本自动收费。

10 · GPT 对话与附件

  1. 新建或选择本地对话，核对模型与账号。模型智能程度和能力受供应商、实际模型、输入质量及上下文影响。
  2. 截图可 Ctrl+V；文件可通过“图片／文档”选择、拖入，或在资源管理器复制受支持文件后粘贴。发送前必须看到附件名称或缩略图。
  3. 文件未出现就不要发送并假定模型已经读取。优先使用文件选择按钮；文档格式、文件大小和图片数量以当前界面限制及供应商能力为准。
  4. 发送后观察回复状态；聊天记录和已发送附件保存在本机。模型推理通过所配置云端接口进行，不是模型完全离线部署。
  5. “保存为记忆”需主动选择；普通聊天不会自动改动商品库或发起视频任务。

若提示上次付费请求结果不确定，应先核对账单与原任务。不要通过反复发送、刷新或新建对话绕过重复付费保护。新建对话不代表此前费用已核对。

11 · 插件下载与手动导入

入口：“状态与设置 → 插件与组件”。语音模型和视频合成浏览器可按需安装；OCR、FFmpeg、核心运行时与 SDK 仍随当前 EXE 内置，不强制拆分。

软件内下载

  1. 核对用途、固定版本、下载大小和磁盘占用，确认后台下载。
  2. 默认国内优先，提供进度、暂停与继续。国内镜像只传输相同字节，不能替程序选择新版本。
  3. 下载完成后还会校验、安装并执行真实运行检测；只有“可使用”才代表本次检测通过。失败不会自动无限重试。

软件内下载失败

  1. 展开该组件的“下载失败？打开备用下载网址／手动导入”。里面列出完整直达网址、每个文件大小和 SHA-256。
  2. 用浏览器下载列出的固定版本原始文件。国内链接不可用时可尝试官方链接；不要下载站点推荐的最新版，不要双击执行下载文件。
  3. 点击“导入原始下载文件”逐个选择。语音模型需要清单中的全部文件，视频合成浏览器需要对应 ZIP，均不用自行解压。
  4. 不完整时会提示已导入数量，不会偷偷改为联网下载。全部齐全后程序重新核对哈希并安装、运行检测。
  5. 已有本程序导出的专用包时，使用“导入离线组件包”。普通官网 ZIP 应走原始文件入口，不能混淆。

程序不保证任意网络都能打开外部链接。若所有链接都被网络策略阻断，可在可联网环境下载清单中的相同文件后复制回来导入；不能通过关闭 TLS 或跳过哈希校验解决。

清理下载缓存不会删除用户素材、历史或配置，但以后修复可能需要重新下载。独立插件自动更新须配置正式可信发布源；按钮关闭时不代表可以安装任意第三方“插件”。

12 · 任务、历史与费用

状态处理方式
排队／提交／生成中等待并查询原任务；不要重复提交。
结果同步／下载中云端可能已完成，等待文件下载和校验。
结果未知／待核对不能当成失败或免费，先核对供应商任务和账单。
已完成打开本地输出并检查质量；完成不等于广告可用。
失败／暂停查看具体原因；只有确认原任务状态后才决定重试。

任务中心显示跨模块状态，共享视频并发池。刷新记录是查询，不应重发生成。关浏览器通常不停止后台任务；完全退出 EXE 或关闭电脑则可能中断本地下载／合成，重启后需核对原任务。

余额、预估报价、模型返回用量与最终账单不是同一数据。报价缺失不能显示成零费用；比较成本必须同时比较相同规格下的可用成片，缺少账单证据的记录不应参与成本排名。

停止本地查询或取消下载不等于取消供应商已接受的付费任务，也不保证退款。

13 · 本地数据与备份

在“文件与空间”查看当前工作区和空间；在“状态与设置”创建迁移备份，需要成片时选择包含生成结果。备份完成后先确认文件存在且可读取，再升级或更换电脑。

导出设置不含密钥；迁移资料不等于迁移 Windows DPAPI 凭据。新电脑需要重新输入密钥。对话、素材、备份可能包含商业信息，分享前自行检查。

不要删除正在运行的数据库、组件安装目录或用户数据目录，不要在运行时用旧备份覆盖数据库。卸载时认真阅读是否保留数据的提示，重要资料应有独立备份。

提供给维护人员时优先使用软件“导出安全诊断包”。不要直接发送完整数据目录、原始日志、账单截图或含密钥的配置。

14 · 常见故障处理

启动失败、502 或页面空白

先确认启动的是新安装的快捷方式，等待启动流程结束；保留错误窗口中的日志路径。不要把另一个程序的 HTTP 200 当作后台就绪，也不要随便结束未知进程。重新启动仍失败时导出／保留诊断信息交给维护人员；不要用反复安装代替定位错误。

端口占用、重复启动

从同一快捷方式启动，等待已有实例；不要自行写死服务端口。软件应使用实际就绪地址，复制旧 localhost 地址可能打不开。

接口报错、模型不可用

检查账号启用状态、Base URL、实际模型 ID、额度、权限和网络。HTTP 401/403 通常需要核对身份或权限，429 需要核对限额；这些代码不应自动触发付费重发。自定义接口须按协议单独验证。

插件失败、无法下载

查看组件日志、磁盘空间、固定来源和哈希错误。按第 11 章用网址下载并导入；不要关闭证书校验、安装未知下载器或以错误版本替代。哈希不匹配说明不能信任当前字节，应重新下载。

音视频无法处理、缺少声音

先试听／播放原文件，检查时长、编码、音轨和授权；再运行本地技术检查。音色参考不会自动复用音频内容。语音识别还受 CPU 与模型组件可用性影响。

附件不出现／成片不符合预期

附件改用选择按钮，确认名称或缩略图后再发送。成片先核对实际模型、素材引用、提示词和规格；一次只改变一个关键变量并设定预算，不要无上限反复试。

15 · 操作检查清单与功能边界

  • 开始前：商品事实正确、素材可读取且有授权、账号及实际模型正确、插件已就绪。
  • 提交前：预览模型／模式／时长／素材／报价；明确本次预算与调用次数。LLM、图片、视频、采集、OSS 可能分别计费。
  • 完成后：确认真实任务完成、下载有效文件、播放并检查商品一致性、声音、字幕和画面，再保存评审。
  • 故障时：保留原任务 ID、状态和安全诊断；UNKNOWN 不按失败重发。
  • 升级前：创建并检查备份；升级后核对配置、历史、素材和插件状态。

第三方账号权限、网络、平台下载限制、模型随机性和供应商计费规则不受本软件控制。界面上存在选项，不代表供应商已支持或当前账号有权限。使用指南不承诺生成成功率、广告效果或收益，也不替代实际验收证据。

指南随应用版本内置更新，不从远端加载说明脚本，不读取或输出你的密钥、对话或私人数据。
