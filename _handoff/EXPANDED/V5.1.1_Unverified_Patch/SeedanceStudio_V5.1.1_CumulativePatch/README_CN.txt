Seedance Studio V5.1.1 累积补丁（安全优先）

【注意/Risk】当前交付已完成 Python/JS 静态检查和模拟风险测试；尚未在真实 Windows Hypit CLI 0.3.1 环境验证完整免费构建成功。请勿在免费预检未成功前尝试实际付费生成。

1. 完全退出 Seedance Studio 服务端。
2. 把补丁文件夹解压到现有 Studio 根目录（与 00_START.cmd 同级）。
3. 双击本补丁文件夹中的 01_APPLY_PATCH.cmd。支持 V5.0.0、V5.0.1、V5.0.2、V5.0.3、V5.1.0 直接升级至 V5.1.1。
4. 用原启动入口启动，打开「爆款复刻（Hypit）」。
5. 如未安装官方 Hypit，先点「一键准备官方 Hypit 环境」。
6. 点击开始复刻后，系统会先执行本地 Hypit 免费完整构建；只有官方构建成功且导出成功后，才可显示并确认 OpenLux 付费费用。
7. 不支持跳过预检。不认识的 Hypit Pricing/Plan 结构或可能产生云端费用的 Hypit 请求会阻止生成（保护费用）。
8. 回滚：完全停止服务端，再双击 02_ROLLBACK.cmd；仅回滚最后一次 V5.1.1 补丁文件。

无新增 OpenLux 费用。Hypit 免费预检会使用 CPU、磁盘、可能联网下载官方依赖，首次执行会耗费时间。该流程不能保证最终 AI 创意质量，但可提前识别本地 Hypit 构建链路失败。
旧版项目、API Key、OSS 设置、原始数据及生成视频由升级脚本保留；安装前自动备份被更改程序文件。
Windows / 官方 Hypit Runtime / OpenLux 网络真实执行仍需在用户电脑上验证；若检测失败，保护性阻断优先，不允许自动改用收费请求。
