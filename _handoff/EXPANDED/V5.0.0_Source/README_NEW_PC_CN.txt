更新日志请查看根目录唯一的“版本更新汇总.txt”。

Seedance Studio V4.2.8.19 | 新电脑安装与启动

根目录只需操作两个 CMD 文件：
  1. 01_INSTALL.cmd    首次安装时双击一次；失败可重新运行，集中安装依赖。
  2. 00_START.cmd      安装成功后每次双击，自动打开工作台，CMD 会很快退出。

音频使用方式：只有添加音频素材时出现。默认“参考音色（仅使用上传音频的音色）”；也可切换“使用上传音频的内容，保持上传音频的音色”。
无音频时正常走原来的生成流程。此次修复单选按钮占满宽度导致中文逐字竖排的问题。

不要手动运行 tools 内的脚本。首次安装需要联网；安装器不会附带 Python 安装程序或本地模型的大型离线镜像。
如果安装失败，查看 install_logs/python_setup_v426.log 和 dependency_report.json。
打开网页失败，查看 data/startup.log 和 data/startup_stage.txt。

更新安装到新文件夹时，不要删除旧版本目录、data 或凭据；待任务完成后使用原有迁移流程迁移历史与配置。

【V4.2.8.19 | @音色绑定使用方法】
1. 只有本次任务确实上传音频后才显示“音频使用方式”，仍然只有两项：
   · 参考音色（仅使用上传音频的音色）：上传音频只作为人声音色参考，台词由你输入或视频模型新生成。
   · 使用上传音频的内容，保持上传音频的音色：原始音频将本地合成为成片音轨（上传音频时长不得超过视频时长）。
2. 一个人说话时可直接上传一段音频。多人对话时必须通过 @明确说话人：
   · @image 1 中右边的男生使用 @audio 1 的音色，左边的女生使用模型声音。
   · @image 1 中右边的男生使用 @audio 1；左边的女生使用 @audio 2。
   · 英文同样支持：the man on the right uses @audio 1（右边男生使用第1段音频）。
3. 一张图片可能有多名人物，单独写“@image 1 使用 @audio 1”不足以标识其中哪一个人。
   多人对话无法判定绑定时，点击“调用预览”会提示修改提示词；不提交付费任务。
   同一段音频内包含多人讲话时请先裁剪成单人音频再分别绑定。
4. 预览页面会显示“@audio N → 角色”绑定结果。后台把绑定文字传给 Seedance 2.5；
   OpenLux/视频模型是否精确执行角色分配以及音色还原，仍然需要实际生成核查。

【美化版安装进度】
安装器显示五大验证阶段，Python 依赖安装时显示七个子阶段。官方 Python 安装包下载
在服务器提供 Content-Length 时显示实际 MB 和百分比。其他阶段展示已完成的里程碑，
不把未知的模型下载/安装时间伪造成百分比。
首次在全新 Windows 10/11 64 位电脑安装需要互联网；压缩包是应用源码及安装器，
不包含大型 Python/FFmpeg/模型离线文件。安装失败时可重复运行 01_INSTALL.cmd，
保留已有数据和配置。电脑更换后加密的旧机密钥一般无法直接跨 Windows 用户解密，
请在新电脑工作台设置中重新配置 API Key（不要发到聊天中）。

【V4.2.8.19｜新电脑安装显示和FFmpeg下载修复】
- 解决Windows PowerShell 5.1读取Python UTF-8中文输出时的乱码问题（强制Console.OutputEncoding和PYTHONIOENCODING为UTF-8）。
- FFmpeg/FFprobe首次下载显示服务器报告的文件大小、真实已下载MB、传输速度、预计剩余时间，不再只有一句“正在下载”。没有Content-Length时仅显示实际MB，不虚构百分比。
- 首选Gyan.dev，网络连接失败或压缩包无效时自动尝试GitHub BtbN镜像；连接单次超时35秒，完整下载最长20分钟，失败可双击01重新尝试。
- 安装完成后运行00_START.cmd。ZIP只包含软件源码和安装脚本，依赖需要联网取得；如果网络不允许访问两个下载站，会给明确错误提示，不会假装安装成功。
