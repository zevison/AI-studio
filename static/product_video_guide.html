Seedance Studio｜从商品资料到 TikTok 商品视频
适用：本安装包的商品知识中心、热点收集、智能视频制作和官方 Hypit 页面。

一、第一次安装与准备
1. 把完整 ZIP 解压到独立、本地、可写的目录，例如 D:\SeedanceStudio。不要放在 Program Files、网盘同步目录或直接在 ZIP 内运行。
2. 运行 01_INSTALL.cmd，等到安装检查完成，再运行 00_START.cmd。首次安装分析组件需要联网及数 GB 磁盘空间；FFmpeg/ffprobe 已随包提供。
3. 在“状态与设置”配置同事自己的 OpenLux API 密钥、账户只读令牌。参考素材需要外部可访问地址时，再配置 OSS。
4. 用 Bright Data 采集 TikTok 时，还需要该服务的密钥，并按自己的账户核实采集计费与剩余额度。不要把别人的余额数值照填过来。
5. 先做系统体检。缺失必需组件先关闭工作台，再重跑 01_INSTALL.cmd；没有配置某项服务，就不要启动依赖它的阶段。
本软件无需安装 ChatGPT，也无需开启 ChatGPT Work 浏览器权限。聊天推理和视频生成使用在线服务，不是离线模型。

二、正确理解“自动”
程序负责整理资料、抽取真实视频画面、调用模型拆解并改写脚本，以及交给 Hypit 编排和合成。
选择商品、核实事实、选择参考视频、批准脚本和审核成片由操作人完成。
采集、LLM 编排/拆解和新视频生成可能分别计费，页面需要各阶段确认。打开页面、保存任务或绑定已有成片，不等于同意付费。
未经报价与授权，不会自动启动新视频生成。本流程不是无人值守批量投放，也不会自动发布到 TikTok。

三、商品知识中心：先建立可靠商品资料
1. 点击“新建商品”，填写明确的商品名称、美国市场使用场景。
2. 添加商品链接、说明书、规格与商品实拍图片。不要只粘贴竞品的宣传语。
3. 使用商品解读功能前检查模型与费用；完成后逐条复核事实及搜索关键词。
4. 至少把一条有来源支持的商品事实标为已确认/verified；保留禁止宣传的功能、性能和限制。
5. 保存商品。生成广告时只能把已核实事实作为商品功能依据，不能把参考视频中竞品的能力转移给本商品。

四、热点收集：寻找候选，拿到真实视频
1. 选择刚才的商品，检查关键词；先采集较少数量，例如 10 或 20 条。
2. 点击“预览关键词与额度”，核对本次总量和账户计费，再决定是否点击“确认并手动采集”。
3. 等待同一采集任务更新。长时间等待时查看历史任务与错误记录，不要连续重建采集任务。
4. 逐条观看候选，选一条与商品使用场景相关的视频。观看量、点赞量不是订单或转化率证明。
5. 获取原视频，或上传你已获得的原视频并绑定到该候选。仅有链接、封面、标题或截图，不能作为完整视频拆解的输入。
6. 确认页面显示真实视频已就绪，再进行下一步。视频失效、无法下载或素材损坏时应先换源/重新绑定，不要反复调用模型。

五、真实视频拆解与商品匹配：生成可审核脚本
1. 一次选择一条已绑定真实视频的候选，点击“检查视频并预览费用”。
2. 检查视觉模型、预估费用和预算。报价无法核实时先处理账户报价配置，不能把未知价格当免费。
3. 单次确认后，程序提取真实画面并让模型输出时间点拆解、商品匹配依据、可迁移镜头和中英双语脚本。
4. 本地语音识别若不可用，不能把模型补写内容当成原视频真实口播。稀疏画面分析也不能证明每个动作细节都已识别。
5. 商品匹配不合适、事实未核实或脚本解析失败时，不要直接用于广告。查看错误及原始结果，修正资料或选择另一条视频；失败请求也可能已经计费。

六、智能视频制作：确认脚本，再选择制作方式
1. 从已完成脚本中选择一条，点击“创建制作审核任务”。重复点击已有脚本会复用原任务。
2. 编辑英文开头、中文对照、每个镜头的场景与口播；检查商品事实、美国日期与季节。点击“确认脚本并保存”。
3. 跨日或跨季节的旧稿，应点击“保留旧版，按当前美区日期重新复核”，重新检查文字后再确认。更新日期不是自动证明旧内容仍适用。
4. 推荐先选 Seedance 2.5 或自动，然后使用“建立并打开 Hypit 制作任务（不扣费）”。选择商品实物图片/视频时必须选当前商品的素材。
5. 如果使用其他模型的首版测试入口：先核实该账户是否支持真实接口和价格，再到“视频创作”预览、确认生成。模型名称出现在列表里不代表接口已实测可用。
脚本移交会同步总时长、9:16 比例和本次参考视频，避免沿用上一段视频的旧参数。超过单段时长范围时改走 Hypit 分段编排，不会偷偷缩短脚本或开始收费。

七、Hypit：编排、合成或等待视频生成批准
1. 已审核脚本、商品事实、限制与参考视频会绑定到同一个 Hypit 工程；重复打开不会偷偷建立另一份付费任务。
2. 检查创作要求及素材，读取模型报价，设置编排预算与最多尝试次数，确认后启动 AI 编排。
3. 只使用现有素材且官方检查通过时，可自动本地合成。需要新画面时，工程会停在等待视频费用批准的阶段。
4. 需要新视频时先核对上传素材、视频报价与预算，再单独批准。不要把编排费上限理解为视频费已经包含在内。
5. 等待“制作完成”，观看预览并下载成片。直接真人脸参考和已验证音色克隆不支持；延长及混合参考仍属于实验能力。

八、回到审核队列完成闭环
1. 回到“智能视频制作”，选择原来的制作审核任务。
2. 点击“核验并绑定 Hypit 已导出成片（不扣费）”。系统核对工程归属、任务完成状态和本地文件校验后，进入成片审核。
3. 在页面播放/下载成片，核实商品外观、功能、字幕、节奏与声音。通过后点击“通过首版效果”。
4. 不满意时填写具体原因后“退回修改”，再“保留旧版，按当前美区日期重新复核”，编辑脚本并重新确认。旧脚本、旧工程、成片及意见会保留，后续重新制作仍需相应费用授权。
5. 普通视频创作生成的成片，使用该页的任务编号绑定入口；不得拿不属于本次任务的历史视频充当首版。

九、常见问题与处理顺序
• “没有可用脚本”：先确认热点拆解结果为 completed，并且商品匹配和脚本校验已通过。
• “至少一条有依据的商品事实”：返回商品知识中心，补充来源并人工核实；不要为了通过检查凭空标记。
• “真实视频未就绪/抽帧失败”：检查原视频能否播放、文件是否存在、FFmpeg与图片处理组件是否完整。
• “日期/季节不一致”：对现有审核任务执行重新复核；修改季节表达后再次确认。不要改系统时钟绕过检查。
• “Hypit 尚未完成合成”：先在 Hypit 导出完成，再绑定；仅有编排方案不是成片。
• “成片已修改/丢失”：恢复对应原文件或重新导出，不要把其他视频改成相同文件名冒充。
• “请求结果不明/连接中断”：刷新原任务，查看供应商任务/账单；恢复查询不能重新创建生成请求。GPT 聊天可确认保留旧请求后继续新的问题。
• 安装未完成：保留 install_logs/dependency_report.json 和日志；关闭后台后重跑安装，不删除旧数据，不连续重装多个版本。

十、发给同事前应说明
每台电脑使用自己的配置；安装包不含你的密钥、数据库和素材。升级到独立目录，关闭旧后台后用迁移工具复制配置与历史，保留旧目录用于回退。
首次依赖下载、供应商接口、TK 原视频有效性、账户模型权限都可能因电脑或账户不同而失败；安装通过不等于外部平台永远可用。
本包附本地回归与模拟链路验收证据。模拟链路通过不能替代真实商品活动的线上效果验收，也不能保证广告转化或宣称所有未知 BUG 已消失。
