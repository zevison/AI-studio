视频模型与 OpenLux 路由控制

          
基础视频模型与路由控制是两件事：模型可以手动设置；路由控制严格按 OpenLux 的 3 种方式执行。默认采用“模型名后缀 + 成功率最高”，优先保证生成成功率。


          
          
          
这里选定全局默认模型；「视频创作」和「智能视频制作」均可覆盖。保存后重新读取确认。选择不代表当前渠道已开放该模型，更不会自动发起付费任务。


          

          

          

            
① 模型名后缀成功率最高 → :stable；速度最快 → :nitro；价格最低 → :floor。优先级最高，默认使用。

            
② provider.sort模型名不加后缀，请求体写 provider.sort = success_rate / speed / price。

            
③ Token 默认请求中不写后缀，也不写 provider.sort；完全继承 OpenLux API Token 设置页的 routing_priority。

          

          
OpenLux 优先级：模型名后缀 ＞ provider.sort ＞ Token 级默认 ＞ 系统全局权重。选择 Token 级默认时，本地工作台不会覆盖你在 OpenLux 控制台里的设置。
