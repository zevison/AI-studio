Seedance Studio V5.2.0 完整安装包｜2026-10-19

使用：
1. 解压到独立、路径较短的本地文件夹，建议避免网盘同步目录。
2. 双击 01_INSTALL.cmd，等待安装检查完成。首次需要联网下载 Python/分析组件，可能占用数 GB 空间；不要提前关闭窗口。
3. 双击 00_START.cmd。到“状态与设置”保存 OpenLux API 密钥、账号只读令牌和需要使用的 OSS 配置。已有当前 Windows 用户的共享凭据会复用。
4. 打开“AI 视频制作 · Hypit”：选择参考视频，填写要求，保存任务；确认编排预算后启动 AI。视频生成需要另外查询价格并确认。

从旧版升级：
请解压到新文件夹，不要覆盖旧文件夹。关闭新旧版后台后，在新版 tools/maintenance 中运行“05_迁移旧版配置和历史.cmd”，选择旧版文件夹；有运行中或提交不明的任务时会拒绝迁移。
迁移使用 SQLite 一致性快照，不合并覆盖已有用户数据库。保留旧文件夹用于回退及旧工程绝对路径引用；不要删除它。
回退：关闭新版后台，启动保留的旧版。新版产生的任务和素材仍保存在新版目录，不倒退覆盖数据库。

本版已实测的主要链路：
官方 Hypit 0.3.1 Skill / Agent 工程编写与自修复、check/plan、本地 Film 合成和 Studio；Seedance 2.5 文生视频，以及单个非人物参考视频编辑（720p、自适应比例、不生成声音）；原任务恢复不再提交生成。
参考编辑测试经历了主机语法适配和恢复修复，原始输出及修复记录均保留；随后独立 Agent 编写验收无需人工改写源码，通过了官方检查、计划和素材绑定。

明确的功能边界：
- 不支持通过当前接口直接上传真实人脸进行人物替换；音色复刻接口尚未验收，不能宣称已完成音色克隆。
- 其他参考生成、延长、混合图片/音频条件仍为实验模式，报价与授权会提示风险；不自动切换到其他更贵模型。
- 模型费用和视频费用分别授权。供应商没有服务端金额硬封顶，预算门禁基于实际账号报价及预留；最终以账单为准。
- 网络超时或提交结果不明时隔离，不自动重发。视频可恢复原任务；模型结果丢失须先核对正向账单，不能以“未看到扣费”重试。
- 安装已在本机隔离目录实测，复用了现有 Python/Tesseract；不声称已测试所有全新 Windows、显卡、语种或业务素材。首次语音识别可能另需下载本地模型权重。

完整源码、官方依赖、浏览器与 Node 载荷在本包内。安装器统一处理运行环境；本包不是纯补丁，也不包含用户密钥、历史数据库或用户素材。
详细版本和验收证据见 VERSION_REGISTER.json、docs/集成验收_20261019.md。遇到安装问题查看 install_logs；无需反复下载另一个补丁。

本轮补充：FFmpeg/ffprobe 的官方校验 ZIP 已随包提供，缺失时优先离线安装；其余首次依赖仍可能需要网络。Hypit 使用方法见 docs/Hypit_使用说明.txt。
